# 点呼支援レポート（MyGeotab Add-in）

前日の運転データ（急ブレーキ・急加速・速度超過）を **本人の過去7日間** と比較し、
定型コメント付きの点呼用一覧を MyGeotab の中に表示する Add-in です。

## 構想図との対応

| 構想図 | 実装 |
|---|---|
| ① 運行中 / ② 運行終了後 | GO デバイス → MyGeotab（標準機能）。Add-in は `Trip` と `ExceptionEvent` を API で取得 |
| ③ 本人の過去と比較 | 走行100kmあたりの発生回数を「前日」と「過去7日計」で比較し、増加／減少を判定 |
| ④ 点呼用一覧を作成 | 判定に応じた定型コメントを自動入力。ドライバー別（または車両別）に一覧化 |
| ⑤ 翌朝の点呼 | 管理者がコメントを編集・確認済チェック。印刷／CSV出力 |

## ファイル

- `tenkoReport.html` / `tenkoReport.js` / `tenkoReport.css` — Add-in 本体
- `config.json` — MyGeotab に登録する設定（`url` を配置先に書き換える）

> HTML のファイル名と JS 内の `geotab.addin.tenkoReport` は一致させてください。

## 動作確認（ローカル）

`tenkoReport.html` をブラウザで直接開くと、デモデータで動きます（URL に `?demo=1` を付けても可）。

## MyGeotab への登録

1. 3ファイルを HTTPS で配信できる場所に置く（社内Webサーバー、Azure Static Web Apps、GitHub Pages など）
2. `config.json` の `url` を配置先に書き換える
3. MyGeotab：管理 → システム → システム設定 → Add-Ins → 新規 Add-In で `config.json` の内容を貼り付けて保存
4. メニュー「アクティビティ」配下に「点呼支援レポート」が表示される

画面上部のグループフィルターで対象車両を絞り込めます。

## 設定（`tenkoReport.js` 冒頭の `CONFIG`）

- `categories[].ruleIds` — **要確認**。既定はビルトインルール
  `RuleHarshBrakingId`（急ブレーキ）、`RuleJackrabbitStartsId`（急加速）、`RulePostedSpeedingId`（速度超過）。
  カスタムルールを使っている場合はそのルールIDに置き換えてください（複数指定可）。
- `thresholds` — 増加：前日2回以上かつ平均の1.5倍以上／減少：平均の0.5倍以下（過去2回以上）
- `minDistanceKm` — 前日走行がこれ未満なら「参考」扱い（既定 20km）
- `comments` — 定型コメントの文面

## 前提・制約

- **ドライバー別集計にはドライバー識別（NFCキー、アプリでのログイン等）が必要。** 未識別の走行は集計外になり、画面上部に距離を表示します。識別していない場合は「集計単位：車両」を使ってください。
- 日の区切りはブラウザのタイムゾーン（日本なら JST 0時）。
- コメント編集・確認済は **ブラウザの localStorage に保存**（端末ごと）。複数の管理者で共有するなら `AddInData` API への保存に切り替えるのが次の段階です。
- 大規模フリート（数百台以上）では 8日分の Trip / ExceptionEvent 取得に時間がかかる場合があります。必要ならグループで絞るか、集計を夜間バッチ化してください。

## 段階的な拡張（構想図「段階的に拡張」）

1. **今回**：定型コメントで運用
2. 次：週次・月次の本人比較（`baselineDays` を変える／週単位タブを追加）
3. 将来：生成AIでコメント文章化、対応カメラ映像へのリンク
